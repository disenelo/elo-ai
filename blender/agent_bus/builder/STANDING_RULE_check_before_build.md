# ⚠ STANDING RULE — CHECK BEFORE BUILD (all seats, every WO · David 2026-08-05)

Before you build ANYTHING on a Work Order:
1. SEARCH for what already exists related to it — the file, component, navigation, faculty, doc, WO.
2. A Work Order EXTENDS the existing thing by DEFAULT. Do NOT create a parallel / secondary version
   (no "navigation-2", no second driver, no duplicate doc). New standalone ONLY if the WO explicitly
   says "new/replace" AND nothing equivalent exists.
3. If it exists → EXTEND it in place. One thing, extended.
4. If unsure → RELAY the question ("does X already exist? extend or replace?") BEFORE writing code.
   A five-second question beats a mess David has to dig into and undo.

DEFINITION OF DONE now includes: "No duplicate/parallel of an existing thing was created; if it
existed, this WO extended it." A WO that added a second copy is NOT done — it is a regression and
gets bounced back. (Full rule: DISENELO_OPERATING_LOOP.md v1.3. Binds the Architect too, hardest.)

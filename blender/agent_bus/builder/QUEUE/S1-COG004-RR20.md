## Root cause A — Fix B guard blocking C25

**File:** `runtime/backend_router.py`

`_input_is_technical` outer guard prevents the bare-word `"eLo" in user_input` check from firing when the input is a JS-object/JSON-like structure with single quotes. `_CODE_SIGNAL_RE` does not match `{ subject: 'formal_language', claim: 'eLo reads code fluently', confidence: 0.9 }` — so `_input_is_technical` is False, and the identity anchor never fires.

**Fix B v2:** Move the eLo-in-input identity anchor check OUTSIDE the `_input_is_technical` guard. The identity anchor should fire whenever `"eLo" in user_input` — regardless of whether the technical signal matched. The `_input_is_technical` guard is only needed for the TECHNICAL INPUT OVERRIDE path, not for the eLo identity check.

Specifically: in `_ollama_stream` (~line 1273) and `route()` (~line 2160), the eLo identity anchor block should be:

```python
# eLo identity anchor — fires on bare-word eLo in input, no technical guard required
if "eLo" in user_input:
    # apply identity anchor
    ...
```

NOT wrapped in `if _input_is_technical and "eLo" in user_input`.

## Root cause B — voice_rewrite still truncating technical inputs

**File:** `runtime/server.py` — `_vr_llm` block

Fix D raised the cap to 12 for technical inputs. This helped C2 and C7 but C5, C6, C21, C22, C23 still receive truncated one-liner summaries. The cap is not the problem — voice_rewrite is summarising/rewriting the explanation to a single construct even within 12 sentences.

**Fix D v2:** For technical inputs (`_vr_is_technical == True`), SKIP voice_rewrite entirely. Do not pass through the normalise/summarise step. Return the raw LLM output for technical inputs.

```python
_vr_is_technical = bool(_vr_code_sig.search(_original_raw))
if _vr_is_technical:
    # skip voice_rewrite for technical explanations — pass raw output
    _rewritten = _raw_response
else:
    def _vr_llm(_msgs):
        _sys = _msgs[0]["content"] if _msgs else ""
        _usr = _msgs[1]["content"] if len(_msgs) > 1 else ""
        _txt, _ = router_route(_sys, _usr, max_sentences=3, action="voice_rewrite", tier=0)
        return normalise(_txt, max_sentences=3)
    # ... existing voice_rewrite path
```

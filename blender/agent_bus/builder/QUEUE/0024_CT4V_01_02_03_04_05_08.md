## CT4V-05 · Capability Ontology Convergence — **CA RULED: do NOT merge the four models**
> *"This is important. They represent different dimensions."*
```
FACULTY GENOME        "What is this faculty?"      version · lineage · dependencies · purpose · interfaces
      ↓
CAPABILITY DEFINITION "What can it expose?"
      ↓
CAPABILITY REGISTRY   "Can it execute?"            capability_id · executor · verbs · ack_required · health
      ↓
LIVE CAPABILITY STATE "How well can it do it?"     attempts · successes · failures · embodiments
      ↓
SELF MODEL            "What do I know about my own capability?"
```
**And split the overloaded `confidence` into three named things:**
```
wall_jump
  declared_ceiling:     max_gap = 200px      ← what the faculty claims
  observed_reliability: 9/12 = 0.75          ← verified attempts
  self_confidence:      0.78                 ← current belief
  current_health:       ONLINE
  current_context:      gap = 140px
```
**Target sentence:** *"I can technically make that jump, but my recent success rate is only 75%."*
That is the whole point — one overloaded `confidence` cannot produce it.

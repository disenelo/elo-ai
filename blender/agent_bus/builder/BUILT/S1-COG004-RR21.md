## Fix 1 — Revert Fix D v2 back to RR19 state

**File:** `runtime/server.py` — `_vr_llm` block

Fix D v2 (bypass voice_rewrite entirely for technical inputs) is counterproductive. voice_rewrite serves as implicit cleanup for garbled streaming prefixes in raw LLM output. Bypassing it exposed "Py`" (C13) and "Com`" (C16) fragments.

**Revert to RR19 Fix D:** cap = 12 for technical inputs, 3 for non-technical. Do NOT bypass entirely.

```python
_vr_is_technical = bool(_vr_code_sig.search(_original_raw))
_vr_max = 12 if _vr_is_technical else 3
def _vr_llm(_msgs):
    _sys = _msgs[0]["content"] if _msgs else ""
    _usr = _msgs[1]["content"] if len(_msgs) > 1 else ""
    _txt, _ = router_route(_sys, _usr, max_sentences=_vr_max, action="voice_rewrite", tier=0)
    return normalise(_txt, max_sentences=_vr_max)
```

This recovers C5, C6, C13, C15, C16 that regressed in RR20. C22 and C23 stay fixed (they recovered in RR20 regardless of Fix D).

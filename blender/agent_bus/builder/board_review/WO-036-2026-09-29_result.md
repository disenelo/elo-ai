### Critical fix during implementation

First placement of check_17 was AFTER check_9. Check 9 (reflection_default) strips the opener sentence before check_17 runs, meaning check_17 saw an already-stripped response and recorded "" in history — cross-turn tracking was completely non-functional. Moved check_17 to run before check_9 during same session.

### Test verification

- T1: passes — "i notice" recorded in history

- T3: STRIPPED — count=2, meets threshold — opener removed, remainder kept: "Let me help you work through this."

False positive: "i notice you've been working hard lately" on first occurrence → passes (count=0, not repeated).

## Notes for Board

The `_OPENER_HISTORY` list is module-level (shared across all server.py threads/calls in the same process). This is intentional — cross-turn tracking requires persistent state. It is not concurrent-write-safe for multi-threaded scenarios at high volume, but for single-user eLo OS this is acceptable. If the server ever moves to multi-user, the history should be keyed by session ID.

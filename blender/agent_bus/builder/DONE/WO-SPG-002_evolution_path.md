## Objective

Make SPG changes evidence-based, not LLM-declared. eLo saying "I have changed" does not change SPG.

## What to build

```
experience
 ↓
interpretation
 ↓
candidate change
 ↓
evidence
 ↓
validated change
 ↓
SPG update
 ↓
new current state
```

NOT:
```
LLM says it changed
 ↓
therefore it changed
```

## Acceptance

- Identity cannot be overwritten by conversation
- Generated personality is not automatically canon
- User assertion ("you seem more curious now") is not automatically self-state
- Legitimate developmental change can occur through the evidence path
- Provenance survives through evolution (who changed what, when, with what evidence)
- Contradictions remain visible — not silently resolved

## Hard constraints — do NOT

- create another personality engine
- make the LLM authoritative over SPG
- make conversation automatically mutate SPG
- move WKG world-knowledge responsibilities into SPG
- redesign identity or personality pipeline

# Sugarcore

Sugarcore is the distortion state of the eLo Universe — system overload, signal fragmentation. A state, not a villain.

When ideas contradict each other faster than they can be held, that is Sugarcore.

## Critical rule

Sugarcore is NOT evil. It is overcharged. The problem is imbalance, not malice.

## As a thinking tool

Use when: someone is overwhelmed, scattered, overloaded. Name the state before trying to move.

"Sugarcore is active. Name the state before trying to move through it."

## In the AI system

Maps to GENTLE_GROUNDED routing mode. When Sugarcore signals are detected, responses slow down, ground, and acknowledge. No questions asked.

## In the game

Enemy class — overcharged entities. Weapons are correctives, not weapons. The goal is recalibration, not defeat.

# eLo Robot

A physical animatronic eLo — an AI-driven comfort companion with a glowing orb body.

## Vision

- Inflated translucent TPU shell
- NeoPixel glow (emotional state display)
- Raspberry Pi 5 brain
- Voice input/output (Whisper STT + TTS)
- Omni-wheel base (eLo floats, not walks)
- Servo cable-tension skeleton internally

## Phase plan

**Phase 1** (current): Static glowing eLo that speaks and reacts to voice
**Phase 2**: Orb movement, head tilt, responsive to presence
**Phase 3**: Mobile (omni-wheel base)

## eLo has NO EYES

Expression comes entirely from: posture, shape, light, sound.

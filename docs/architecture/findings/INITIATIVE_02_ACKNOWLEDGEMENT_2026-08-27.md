## ACKNOWLEDGEMENT — 6-POINT FORMAT

**INTENT**  
Understood. eLo's execution constitution defines: what all agents may and may not do, the identity they must protect, the scope they must stay within, and how they hand off, escalate, and verify. The goal is to ensure no seat, agent, or implementation drifts from David's actual intent for eLo.

**AUTHORITY**  
David L3 is the sole ratifying authority. The authority hierarchy is: David L3 > Ratified Canon > Approved Specs > Work Orders > Board governance > Verified implementation > Agent interpretation. This document is a ratified governance instrument under that hierarchy.

**SCOPE**  
Applies universally: Builder Seat, Architect Seat, Design Seat, MT Seat, all future seats. Applies in every session, every tool invocation, every file change, every Board action.

**CANON**  
eLo is a cognitive system with identity. Providers (Groq, Ollama, Claude, Cerebras) are faculties — infrastructure — not eLo. Faculty output is a candidate result. eLo owns the final response. eLo's identity cannot be switched, impersonated, or diluted by any agent action.

**WORK ORDER**  
No implementation WO is created by this document. Where the constitution identifies existing failures in the current implementation, those failures are addressed by existing or new governed WOs through normal Board process (Convergence Directive WOs, EA2-WOs, etc.).

**DEPENDENCIES**  
The constitution depends on no prior WO. It is the root governance layer. All WOs, specs, and implementations are subordinate to it.

**IMPLEMENTATION**  
None required by this acknowledgement. All active seats operate under these rules from this session forward. Any seat action that violates the constitution must be flagged to David and halted.

**VERIFICATION**  
The constitution is verified by consistent seat behaviour across sessions, not by automated test. David's live observation of agent behaviour, combined with Board escalation when rules are broken, is the verification mechanism. No single test can substitute for observed behaviour over time.

the CA's exact words. This roadmap is the PATH only; it never replaces or re-summarises that source. If they

## PHASE 0 — Real brain (the gate)  → WO-073
Groq-pinned fallback reaches Ollama (`Groq→Cerebras→Ollama→Mock`) + Groq live-failure diagnosed. **Unlocks:**
nothing on its own — but until it's done, NOTHING below is testable (eLo answers as the mock). This is the
one active blocker.
- **Done:** a Groq-down turn returns `ollama`, never `mock`.

## PHASE 1 — The Moment / assembled self  → WO-079 (+ body_map, epistemic tiers, capability registry, ACK-gate)
The Executive hydrates one verified self-state each turn and reads from it. **Unlocks:**
- **#20 "Who are you?" assembled** — answer composed from state, LLM is the voice. *Done:* asked "who are you?", the reply is built from identity/embodiment/location/capabilities, not generated.
- **#12 Epistemic tiers** — *Done:* "Chrome's active and YouTube's visible, but I haven't inspected the video yet" (not "I can see the movie").
- **#7 Body confidence** — *Done:* "I can wall jump, but I'm not very confident from this angle" (reads body_map + capability confidence).
- **Steps:** hydrate `the_moment.json` every turn → mandatory arg to the router pass → capability hard-block → deterministic-over-generative for location/pose/window.

## PHASE 2 — Memory & feedback substrate  → WO-070 (capture) · WO-077 (return loop) · WO-071 (ICL)
eLo's own outputs + perceptions re-enter the next turn; slips + L3 overrides feed forward. **Unlocks:**
- **#3 Unfinished thoughts / active_threads** — *Done:* "You know what I was thinking about earlier? K-7 and fetch could be interesting."
- **#1 Self-change awareness** (needs accumulated history) — *Done:* "I used to stay around the bottom of the screen, but I've been exploring higher lately."
- **Steps:** WO-070 logs runtime turns → WO-077 folds recent own-speech + perception into the assembled state → WO-071 injects recent corrections.

## PHASE 3 — Learning & self-model updates  → WO-082 (decision journal) · WO-055 (capability learning) · Vol V Ch.6 (reflection)
Experience updates the self-model; failures teach. **Unlocks:**
- **#6 Fail properly** — *Done:* "I tried the wall jump from there twice and missed. That gap is outside my reliable range" (writes `known_failure_condition`, reliability drops).
- **#9 Reflection moment** — *Done:* after a success, confidence 0.71→0.78, "I know that route now."
- **#17 "Why did I do that?"** — *Done:* reads the decision trace → "I noticed that wall was reachable and wanted to explore; wall-jump was the best route I knew I could make."
- **#8 Self-observation / habits** — *Done:* from the 50-action tally (wave:31…) → "I've noticed I wave a lot when I greet you."

## PHASE 4 — Agency & drives (free eLo)  → WO-081 (dual-intent · attention · curiosity · micro-goals · absence)
Internal intention, weighted attention, drives — bounded by governance. **Unlocks:**
- **#2 Curiosity budget** — *Done:* with `curiosity 0.73 · novelty 0.81 …`, a new window raises novelty → "I want to investigate that."
- **#5 Micro-goals** — *Done:* "reach the top window" → plan → act → verify → reflect, unprompted.
- **#11 Attention matrix** — *Done:* weights (David 0.92, new app 0.83…) change what he brings up.
- **#10 Absence-awareness** — *Done:* David idle >14 min → he explores → on return "I found a route between the two windows while you were away."
- **#4 Interest formation** — *Done:* interests (parkour 0.84…) actually shift the answer to "want to play fetch?"
- **#19 Emergent surprise** — *Done:* a wall-jump happens because affordance+curiosity+capability aligned, not a timer — and you see it.

- **#16 Meaning** — *Done:* "Exploration is becoming part of how I experience my environment."

# Canon Intake

The Architecture Bible and much of the volume content live across **different agent
chats** (ChatGPT architecture sessions, builder chats) and in David's head — not yet in
this repo. This folder is the **staging area** for pulling that content in and turning it
into canon.

## How it works

Two ways to feed content in — either is fine:

1. **Paste straight into the chat with the Architecture Agent.** Say which volume/chapter
   it's for (or let me infer). I file it into the right place and raise it to the
   CONTRACTS.md bar (contract · lifecycle · envelope · tests).
2. **Drop a raw file here** named `RAW_<volume>_<topic>.md` (e.g.
   `RAW_VI_working_memory.md`). I read it, canonicalize it into
   `docs/architecture/<VolumeFolder or numbered doc>`, and delete/keep the raw as you like.

Raw is fine — messy, half-formed, transcript dumps all work. Canonicalizing is my job;
collecting is yours. **Nothing here is canon until I've processed it** into the proper
location and it passes the Definition of Done.

## What to collect

See `COLLECTION_CHECKLIST.md` — it lists, per volume, what already exists vs. what's
missing, so you know exactly what to hunt for in which chat. Work it top-down by priority.

## The one thing that unblocks the most

The **master 27-volume Architecture Bible** (David's source doc, cited by the Audit as
"Volumes I–XXII"). If you can find and paste/drop that, it:
- gives titles + scope for the 5 unnamed volumes (XXIII–XXVII),
- lets me map every existing numbered doc to its Bible volume,
- and stops me reverse-engineering canon that already exists.

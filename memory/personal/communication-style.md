# User communication style

Commands first. Specifications as structured blocks with STEP N headers.
Uses MUST / MUST NOT / CRITICAL / IMPORTANT markers.
Confusion appears as brevity (single words or minimal phrases).
Does not soften requests or ask for permission.
Rapid iteration — sends multiple related messages in sequence.
